# Automation Rules and Playbooks in Microsoft Sentinel

## Objectives

Automation rules and playbooks in Microsoft Sentinel automate repetitive tasks, speed up threat responses, and improve SOC efficiency by handling alerts and incidents with less manual work.

## How to apply

1. Create via Sentinel Automation (for example, change the severity level)

![Automation rule creation](images/Playbooks-and-Logic-Apps-in-Microsoft-Sentinel/99%20auto%20Playbook01.jpg)

2. Use and tailor the Sentinel Automation template (for example, prompt-user)

![Automation template](images/Playbooks-and-Logic-Apps-in-Microsoft-Sentinel/101%20auto%20Playbook02.jpg)

![Automation configuration](images/Playbooks-and-Logic-Apps-in-Microsoft-Sentinel/102%20auto%20Playbook03.jpg)

3. Create via Sentinel Incident tickets (for example, change the incident status automatically)
